# 棋子套装

2D 棋盘使用的矢量棋子。`npm run pieces` 把这里的 SVG 压缩后生成 `src/view2d/pieces.css`。

| 目录 | 作者 | 许可 | 来源 |
|---|---|---|---|
| `celtic/` | Maurizio Monge | MIT（见 `celtic/LICENSE`） | https://github.com/maurimo/chess-art ，经 lichess-org/lila `public/piece/celtic` |
| `fantasy/` | Maurizio Monge | MIT（见 `fantasy/LICENSE`） | https://github.com/maurimo/chess-art ，经 lichess-org/lila `public/piece/fantasy` |
| `chessnut/` | Alexis Luengas | Apache-2.0（见 `chessnut/LICENSE`） | https://github.com/LexLuengas/chessnut-pieces ，经 lichess-org/lila `public/piece/chessnut` |

改动说明：仅做 SVG 体积压缩（svgo），图形未修改。
